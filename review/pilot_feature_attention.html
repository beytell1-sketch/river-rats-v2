Key Takeaway

All 3 approaches produced identical actions on 19/20 hands. The approach choice only affects the feature attention metadata, not the labels.

Approach B (blank slate) produces the most organic feature tags — agents independently discover the features that matter without pre-tag bias. Tier 2 features like flush_draw_rank, is_preflop_aggressor, and facing_raise were found organically by B agents, showing these are genuinely decision-driving features the model should learn.

Approaches A and C add removal overhead (4.5 and 3.2 per hand) without changing labels. The removal data confirms which Tier 1 features are NOT universal — pot_odds is irrelevant for BET/CHECK hands, villain_draw_pct is irrelevant when draws are 0%.
