## Root Cause Analysis

The v2.3 supplement (486 new hands) is 92% BET+RAISE labels. The resulting training set is 62.8% BET. Despite class weights capping BET weight at 1.0x, the model has learned that BET is the dominant action in multiway checked-to scenarios -- which is exactly what the supplement taught it, but too aggressively.

The model correctly identifies BET spots (perfect 13/13 on MW-50 BET hands) but has lost the ability to distinguish CHECK spots from BET spots.

### Recommended next steps (for owner review)

1. **Rebalance the supplement**: Add CHECK-labelled hands to the v2.3 supplement to bring BET class back toward 40-45%. The Stream C analysis sized 400 hands but assumed the umbrella would include ~20% CHECK hands (per Section 2 bucket distribution). The actual supplement is ~92% BET.

2. **Adjust class weights**: The current weight scheme caps BET at 1.0x. For a 63% BET dataset, a more aggressive cap (e.g., 0.5x for BET) or higher CHECK weight (e.g., 6.0x) may help.

3. **Stratified sampling**: Train on a downsampled BET subset to restore class balance while keeping the supplement's structural diversity.
